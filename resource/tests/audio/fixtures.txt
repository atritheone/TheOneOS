T1OS audio regression fixtures

sample.mp3 and sample.flac contain the same 0.25-second, 440 Hz stereo sine
wave at 44.1 kHz. They were generated by this project for protocol and decoder
tests and contain no third-party recorded material.

Generation tools:
- Python standard-library wave module for the source PCM
- LAME 3.100 for sample.mp3
- FFmpeg 8.1.2 native FLAC encoder for sample.flac

corrupt.mp3 is deliberately invalid input used to verify decoder failures.
